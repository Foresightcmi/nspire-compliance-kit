---

🕒 The Strict 45-Day Rule

Under HUD regulations, you have exactly 45 calendar days from the date of the inspection report release to submit a formal technical dispute to the Real Estate Assessment Center (REAC).

  • If you miss the 45-day deadline, the score is permanent and cannot be contested.
  • Only technical errors, inspector protocol deviations, or local code conflicts qualify for point restoration. (Generic complaints like "the inspector was mean" are automatically rejected).
